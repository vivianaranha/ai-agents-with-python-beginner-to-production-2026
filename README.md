# AI Agents with Python: Beginner to Production — 2026 - School of AI

A complete, project-first course that takes a learner from **basic Python** to **production-grade AI agent applications**.

> Python → APIs → LLMs → structured outputs → tools → agent loops → memory → RAG → planning → MCP → multi-agent systems → evaluation → security → FastAPI → reliability → deployment.

## Why this course is different

Most agent tutorials start after the hard parts. This course starts at the beginning and teaches the engineering underneath autonomous applications: Python, HTTP, state, validation, permissions, persistence, testing, observability and failure handling.

Students do not need a paid LLM API. The repository contains an offline deterministic model, optional Ollama integration, synthetic data, reference implementations, and tests.

## Outcomes

By the end, students can build an AI agent that can understand a task, select validated tools, retrieve trusted knowledge, maintain bounded memory, request approval for risky actions, recover from failures, expose an API, emit traces and metrics, and pass a repeatable evaluation suite.

## Core philosophy

**Learn → Code → Test → Break → Fix → Evaluate → Explain → Ship**

A demo is not production. Every advanced project therefore asks students to define contracts, failure modes, security boundaries, tests, acceptance criteria and operational behavior.
