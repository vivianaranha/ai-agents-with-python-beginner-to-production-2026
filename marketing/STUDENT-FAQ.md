# Student FAQ

## Do I need Python experience?
No. The first modules teach the Python concepts used throughout the course.

## Do I need a paid LLM API?
No. The core course includes an offline mock provider. Optional local and hosted models are extensions.

## Is this framework-specific?
No. Frameworks can accelerate implementation, but the course teaches the underlying contracts, loops, tools, state, evaluation and security first.

## Will I build projects?
Yes. There are 14 portfolio projects plus labs and a capstone.

## Does the course cover MCP?
Yes. The MCP module reflects the July 28, 2026 stateless protocol architecture.

## Is security included?
Yes. Security is embedded throughout and has a dedicated module covering prompt injection, goal hijacking, tool abuse, data leakage, memory poisoning and least privilege.
