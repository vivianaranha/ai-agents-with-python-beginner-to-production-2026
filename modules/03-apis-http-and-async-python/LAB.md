# Lab — APIs, HTTP and Async Python

## Scenario

You are extending an internal **Python Operations Agent** used by a support team. Apply all four concepts from this module to improve one production concern.

## Requirements

1. Define the input and output contract.
2. Implement the smallest working version.
3. Add validation and at least two failure cases.
4. Add unit tests.
5. Record one structured log or trace event.
6. Explain the security boundary.
7. Document how you would operate this feature in production.

## Acceptance criteria

- The program runs from the command line.
- Invalid input fails safely.
- At least three tests pass.
- No credentials are hard-coded.
- README explains architecture and failure behavior.

Connect the lab to the reusable `src/agentpy` course library rather than duplicating infrastructure.
