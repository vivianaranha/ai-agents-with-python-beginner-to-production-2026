# Instructor Guide

This course works as a self-paced GitHub program, cohort bootcamp or classroom course.

## Recommended lesson rhythm

- 10 min: concept and mental model
- 15 min: live coding
- 20–30 min: student build
- 10 min: deliberate failure/debugging exercise
- 10 min: review and questions

## Teaching emphasis

Do not reward autonomy for its own sake. Reward bounded behavior, explicit permissions, deterministic contracts, tests, observability and appropriate human approval.

## Demo rule

For every agent demo, show at least one failure case. Students should see how production systems behave when a tool times out, retrieval returns weak evidence, the model emits invalid JSON, approval is denied, or an untrusted instruction attempts to redirect the agent.

## Grading

Use project acceptance criteria plus the capstone rubric. A polished UI should never compensate for unsafe tool execution or missing tests.
